# RepoRevive – UI Screenshots & Visual Guide

This directory holds visual demonstration screenshots of the RepoRevive founder frontend.

## Key Screens
1. `01_new_idea_wizard.png`: Founder idea prompt textarea with character counter and sample presets.
2. `02_checklist_editor.png`: Interactive feature checklist cards with `must`/`nice` weight toggles and technical keyword tags.
3. `03_results_polling.png`: Live multi-agent analysis progress bar with asynchronous polling.
4. `04_best_match_hero.png`: Best match repository hero card with verified coverage %, viability score, bug risk, and license safety chips.
5. `05_repo_report_tabs.png`: Deep analysis report featuring 7 tabs: Summary, Feature Coverage (linking to GitHub lines), Bug Risk Signals, Score Breakdown, Dependencies, Revival Roadmap, and Agent Trace.
6. `06_founder_brief.png`: Clean executive Founder Brief ready to download (.md) or print/save as PDF.
7. `07_admin_ingestion.png`: Admin ingestion monitoring dashboard tracking GitHub shard filtering counts.
